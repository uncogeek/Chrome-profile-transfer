Chrome Profile Transfer v1.1

نصب:
۱. فایل ZIP را Extract کنید.
۲. در هر پروفایل Chrome به chrome://extensions بروید، Developer mode را فعال کنید و Load unpacked را روی پوشه chrome-profile-transfer بزنید.

استفاده:
۱. در پروفایل مبدأ سایت موردنظر را باز و از طریق افزونه Export بگیرید.
۲. در پروفایل مقصد دقیقا همان origin (پروتکل + دامنه + پورت) را باز کنید و در صورت نیاز وارد حساب شوید.
۳. بهتر است پیش از Import از مقصد نیز نسخه پشتیبان Export بگیرید.
۴. Import را بزنید، فایل JSON سایت مربوطه را انتخاب و سپس صفحه را Refresh کنید.

جزئیات و محدودیت‌ها:
- افزونه در زمان کلیک و فقط برای تب فعال اجرا می‌شود؛ دسترسی دائمی به تمام سایت‌ها ندارد.
- تنها localStorage و IndexedDB همان origin انتقال می‌یابد، نه cookie، sessionStorage، cache، session/login یا اطلاعات سمت سرور.
- به‌طور پیش‌فرض کلیدها و جدول‌های دارای نام حساس (token/auth و...) رد می‌شوند. این تشخیص صرفا بر اساس نام است و امنیت همه مقادیر را تضمین نمی‌کند.
- فایل JSON می‌تواند اطلاعات خصوصی یا حساس داشته باشد؛ آن را به کسی ندهید.
- import فقط روی همان origin که فایل از آن صادر شده قابل انجام است و داده‌های هم‌نام را بازنویسی می‌کند.
- دیتابیس IndexedDB که در مقصد وجود ندارد عمداً ساخته نمی‌شود؛ ابتدا سایت را باز کنید تا ساختار اولیه ایجاد شود.
- با خروجی قدیمی افزونه Faraz Profile Transfer هم سازگار است، البته فقط در origin همان سایت.
- کار روی بعضی سایت‌ها با سیاست‌های امنیتی ویژه یا ذخیره‌سازی خارج از origin فعلی ممکن است کامل نباشد.
